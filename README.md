# 🥡 중국집에서 하는 말 — 수업 자료

## GitHub에 올리기
1. 저장소에서 **Add file → Upload files**로 `index.html`을 올려요. 같은 이름이면 예전 파일이 바뀌어요.
2. **Commit changes**를 누르고 1~3분 기다린 뒤 주소를 새로 고쳐요.
3. 주소는 **Settings → Pages** 맨 위에 있어요: `https://사용자이름.github.io/저장소이름/`

## 수업 흐름 (한 화면에서 차례대로)
- 위쪽 **👧 예나 차례 / 🧒 승호 차례** 단추로 지금 나온 학생을 바꿔요.
- 1 동기유발 → 2 보여주기 → 3 말 차례 놀이 → 4 활동지 → 5 마무리 게임 → 🌟 칭찬 시간
- **보여주기**: 「혼자 / 도움」을 누르면 다음 친구 차례로 자동으로 넘어가요. (🔄 번갈아 하기로 끄고 켤 수 있어요)
- **마무리 게임**: 🏆 주문 왕 게임(고르기 + 🎤 말해 보기) 또는 🗺️ 마을 모험(중국집·카페·햄버거 가게)
- **🌟 칭찬 시간**: 오늘 해낸 것을 보고, 예나와 승호가 서로 칭찬 스티커를 붙여 줘요.

## 내용 고치기
✏️ 편집에서 고친 뒤 「💾 HTML 내보내기」로 받은 파일 이름을 `index.html`로 바꿔 다시 올리면 돼요.
