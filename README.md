# 🥡 중국집에서 하는 말 — 태블릿 수업 올리기

## 1. GitHub Pages에 올리기 (10분, 한 번만)
1. github.com 가입 → 오른쪽 위 **+ → New repository** → 이름 예: `chinese-shop` → **Public** → Create.
2. **Add file → Upload files** 로 `index.html` 을 끌어다 놓고 **Commit changes**.
3. **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://<아이디>.github.io/chinese-shop/` 주소가 생겨요. 이 주소가 수업 자료예요.

> 편집기에서 내용을 고친 뒤 「💾 HTML 내보내기」로 받은 파일을 `index.html` 이름으로 다시 올리면, 고친 내용이 모든 기기의 기본값이 돼요.

## 2. 쓰는 방법 두 가지
| | 그냥 열기 | 실시간 연결 (Firebase) |
|---|---|---|
| 준비 | GitHub Pages만 | Firebase 프로젝트 1개 (무료) |
| 학생 주소 | `…/?s=A` | 「📡 태블릿」 창의 QR/주소 |
| 학생 화면 | 자기 이름·수준만 | 자기 이름·수준만 |
| 선생님 화면 따라가기 | ✕ | ✓ (켜고 끌 수 있음) |
| 기록 모으기 | 태블릿 안에만 | 선생님 화면에 바로 모임 |
| 선생님이 고친 내용 | 다시 올려야 반영 | 바로 반영 |

## 3. Firebase 만들기 (실시간 연결을 쓸 때)
1. console.firebase.google.com → **프로젝트 추가** (애널리틱스 끔).
2. **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 **싱가포르(asia-southeast1)** → **테스트 모드**.
3. **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고 **게시**.
4. 데이터 탭 위쪽의 `https://…firebasedatabase.app` 주소를 복사.
5. 선생님 화면에서 **📡 태블릿 → 주소 붙여 넣기 → 수업 방 열기**. 학생 태블릿으로 QR을 찍으면 끝.

주소를 매번 넣기 싫으면 `index.html` 안의 `const FIREBASE_DB_URL='';` 따옴표 사이에 주소를 넣고 다시 올리세요.

## 4. 📊 결과 보기
- 위쪽 **📊 결과** 단추: 학생별(또는 모두) 활동 결과를 혼자 / 도움 / 다시 / 아직으로 정리해 보여 줘요. 중점 활동에는 「중점」 표시가 붙어요.
- **🖨️ 인쇄**: 학생 한 명이 한 장씩 인쇄돼요.
- 실시간 연결 중이면 **📡 태블릿에도 띄우기**로 학생 태블릿마다 자기 결과를 띄우고, 다시 누르면 닫혀요.
- 학생 태블릿에는 **📊 내 결과** 단추가 있어 언제든 자기 결과를 볼 수 있어요.

## 알아 둘 점
- 수업 방 번호(5자리)를 아는 사람은 그 방 기록을 볼 수 있어요. 학생 이름은 별명이나 이름만 쓰는 것을 권해요.
- 인터넷이 끊겨도 태블릿에서 계속 할 수 있고, 기록은 태블릿에 남아 다시 연결되면 올라가요.
- 태블릿 소리 읽기는 기기에 한국어 음성이 있어야 해요.
